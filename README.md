## Featured Projects

### 🧠 [DocuMind: Multimodal RAG for Technical Documents](https://github.com/aniketmurkutkar/Documind)
Index a PDF once, retrieve only the evidence each question needs, and answer with any LLM. Text, tables and OCR'd images are extracted locally; hybrid FAISS + BM25 retrieval feeds a bring-your-own-key LLM (OpenAI, Groq or any compatible API). [Live demo](https://documind-alpha-six.vercel.app)  
`FastAPI` `React` `FAISS` `BM25` `bge-m3` `PyMuPDF` `Tesseract OCR` `Docker`  
→ Matched a full-document chatbot on 3/3 test questions while sending only the top-k chunks | 92% contextual grounding

---

### 🎙️ [TwinMind Live Copilot](https://github.com/aniketmurkutkar/twinmind-copilot)
Real-time meeting copilot that listens to browser audio, transcribes it in 30-second chunks, and keeps surfacing context-aware suggestions, with a chat panel for follow-ups. [Live demo](https://twinmind-copilot-seven.vercel.app)  
`Next.js 14` `Groq` `Whisper large-v3` `gpt-oss-120b` `Tailwind CSS`

---

### 🦺 [Safety Knights: Careers Platform for Safety Professionals](https://portfolio-orpin-nu-54.vercel.app/#safety-knights)
Led the full-stack build of a job board and community platform (UB CSE 611, presented at Demo Day): job search and filters, saved jobs, applications, a résumé vault, and an admin console for listings, companies and applicants.  
`MongoDB` `Express` `Angular` `Node.js` `RBAC`  
→ 4,000+ registered users and 500+ listings | 40% faster data retrieval with a normalized, indexed schema

### 🏠 [Hybrid Blockchain Land Registry](https://portfolio-orpin-nu-54.vercel.app/#land-registry)
Property records on Ethereum, verified by a government authority layer: smart contracts make ownership tamper-proof, and an automated REST workflow validates documents off-chain.
